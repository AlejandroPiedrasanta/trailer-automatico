INSTALADOR DE MAC (como el de CineCaptions)
============================================
El .dmg se ve con dos pasos: «1 Doble clic para instalar» (el .pkg) y «2 Ábrelo desde Aplicaciones».
El .pkg copia TrailerAutomatico.app a Aplicaciones y su postinstall deja: la carpeta de color de DaVinci con
permiso, ffmpeg (si la app no lo trae: Homebrew), las fuentes de los títulos, las carpetas de trabajo y el
color/ruido en DaVinci (TrailerAutomatico --tarea instalar).

Solo se puede compilar EN UNA MAC (PyInstaller no compila para Mac desde Windows). Dos caminos:

1) En una Mac (con Python 3 de python.org):
     bash PROGRAMA/compilar/mac/construir_mac.sh
   Deja INSTALADORES/Mac/Instalar_Trailer_automatico_Mac_<AppleSilicon|Intel>_<version>.dmg

2) En las Mac de GitHub (sin tener Mac): subir el proyecto a un repositorio PRIVADO de GitHub y correr
   Actions > "Instaladores Mac" (.github/workflows/mac.yml). Los .dmg salen en Artifacts.
   La mezcla de fiesta (>100 MB) se sube partida en trozos *.parte01, *.parte02 (construir_mac.sh la une).

Archivos:
  construir_mac.sh ....... venv -> ffmpeg estático -> PyInstaller (.app) -> autoprueba -> .pkg -> .dmg
  trailer_mac.spec ....... receta de PyInstaller (BUNDLE)
  pkg/scripts/postinstall  tareas al instalar (como el usuario de la Mac)
  pkg/recursos/*.html .... bienvenida y final del instalador de Apple
  dmg/fondo_dmg.py ....... dibuja fondo.png y fondo@2x.png (660 x 460)
  dmg/ajustes_dmg.py ..... ventana del .dmg (dmgbuild): dónde va cada icono
  Desinstalar.command .... quita la app (las carpetas de trabajo no se tocan)
Sin firma de Apple (Developer ID) la primera vez se abre con clic derecho > Abrir (lo dice el fondo del .dmg).
